## Settlement Fee Calculation Flow

```
┌────────────┐     ┌──────────────┐     ┌──────────────┐     ┌────────────┐
│   GROSS    │     │   REFUNDS    │     │     MDR      │     │    GST     │
│  ₹100,000  │  -  │   ₹5,000    │  =  │  Eligible:   │     │ 18% of MDR │
│            │     │              │     │   ₹95,000    │     │            │
└─────┬──────┘     └──────────────┘     │  MDR (2%):   │     │  ₹342      │
      │                                  │   ₹1,900    │     │            │
      │                                  └──────────────┘     └────────────┘
      │
      │     NET PAYOUT = Gross - Refunds - MDR - GST
      │     NET PAYOUT = ₹100,000 - ₹5,000 - ₹1,900 - ₹342
      ▼
┌────────────┐
│    NET     │
│  ₹92,758  │  ──→  Transferred to Merchant's Bank Account
│            │
└────────────┘
```
